# Jasmine Banks - Sophisticated Academic Portfolio

A clean, modern, and sophisticated academic portfolio website showcasing Dr. Jasmine Banks' research in digital psychology, AI ethics, and technology studies. Featuring an elegant beige/cream aesthetic with geometric design elements.

## 🎨 **Design Philosophy**

This portfolio embodies sophisticated minimalism with:
- **Clean, sophisticated aesthetic** inspired by modern academic design
- **Warm beige/cream color palette** creating an inviting, professional atmosphere
- **Geometric diamond elements** adding visual interest without distraction
- **Elegant typography** combining Playfair Display and Inter fonts
- **Subtle animations** that enhance rather than overwhelm

## 🔧 **Customization Options**

### **Easy Color Updates**
All colors are defined as CSS custom properties, making theme changes simple:

```css
:root {
    --sage-green: #your-color;
    --dusty-blue: #your-color;
    /* Update any accent color easily */
}
```

### **Typography Adjustments**
Font families are centrally defined:

```css
:root {
    --font-display: 'Your Display Font', serif;
    --font-primary: 'Your Body Font', sans-serif;
}
```

### **Animation Controls**
All animations respect user preferences:

```css
@media (prefers-reduced-motion: reduce) {
    /* Animations automatically disabled */
}
```
